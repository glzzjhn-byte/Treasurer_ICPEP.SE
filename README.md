# 🏛️ ICPEP.SE Officers Directory

Welcome! This repository holds the official list of officers in the `officers.json` file. 

To add your name to the directory, you must submit a Pull Request. We have an automated system that checks all submissions.

## ⚠️ The Rules
Before you edit the file, please read the rules. If you break these, our bot will automatically reject your submission:
1. **Do NOT delete or change anyone else's name.** You are only allowed to add your own data.
2. **Character Limit:** Your name/input must not exceed **30 characters**.
3. **Valid JSON:** Make sure you keep the exact same formatting (don't forget your quotation marks `""` and commas `,`).

---

## 📝 Step-by-Step Guide to Add Your Name

You do not need to download anything to do this. You can do it entirely through the GitHub website!

**Step 1: Open the file**
Click on the `officers.json` file in this repository.

**Step 2: Edit the file**
In the top right corner of the file box, click the ✏️ **Pencil Icon** (Edit this file). 
*(Note: If you don't have direct edit access, GitHub will say it's creating a fork for you—this is normal!)*

**Step 3: Add your information**
Carefully add your name to the list following the existing format. 

**Step 4: Propose your changes**
1. Scroll down to the bottom of the page to the **Commit changes** box.
2. Write a short title for your change (Example: *Add John Gabriel to officers list*).
3. Click the green **Propose changes** (or **Commit changes**) button.

**Step 5: Create a Pull Request**
1. GitHub will take you to a new page showing what you changed.
2. Click the green **Create pull request** button.
3. Click **Create pull request** one more time to confirm.

---

## 🤖 What happens next?
Once you submit your Pull Request, our automated GitHub Action will scan your edit. 
* ✅ **If it passes:** A maintainer will approve and merge your name into the official list.
* ❌ **If it fails:** The bot will block the merge. Scroll to the bottom of your Pull Request to see what error the bot found, fix your mistake, and it will re-test automatically!
